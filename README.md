# CoShip Client Portal Mockup

This repository contains the interactive, sample-data client portal design supplied for review.

## Preview

GitHub Pages publishes `index.html` with the local design runtime and vendor files. The Pages workflow copies those files into its deploy artifact. The page is a visual prototype only; it does not connect to Coship services or real client data.

The sample screens cover overview, inventory, inbound/outbound activity, tracking, invoices, reports, and account/profile interactions. Tracking links open the carrier's public tracking page.
